# Reality Detailing Studio — демо-сайт

Одностраничный статический сайт студии детейлинга: React + Vite + TypeScript, без бэкенда,
без базы данных и без внешних сервисов. Собирается в набор статических файлов и разворачивается
на любом хостинге.

## Запуск

```bash
npm install
npm run dev       # локальная разработка
npm run build     # проверка типов + продакшн-сборка в dist/
npm run preview   # локальный просмотр собранной версии
npm run typecheck # только проверка типов
```

## Публикация

Сайт разворачивается на GitHub Pages автоматически: `.github/workflows/deploy.yml`
собирает проект и публикует папку `dist/` при каждом пуше в `main`. Ту же сборку можно
запустить вручную с любой ветки — вкладка **Actions** → *Deploy to GitHub Pages* → *Run workflow*.

Адрес по умолчанию: `https://vadimwolff.github.io/Demo-site/`.

Путь к сайту определяется на стороне CI: `actions/configure-pages` сообщает `/Demo-site`
для обычного репозитория и `/`, если к Pages привязан свой домен. `vite.config.ts` берёт
это значение из `BASE_PATH`, поэтому **при переезде на свой домен править конфиг не нужно** —
достаточно указать домен в настройках репозитория (Settings → Pages → Custom domain) и
в `index.html` (`canonical` и `og:url`).

Сборка полностью статическая, поэтому её можно так же залить на любой другой хостинг:
`npm run build` и содержимое `dist/` в корень сайта. Никаких серверных настроек и правил
переадресации не требуется — страница одна, переходы по якорям.

### Пока сайт демонстрационный

В `index.html` стоит `<meta name="robots" content="noindex, nofollow">`, чтобы поисковики
не проиндексировали версию с заглушками вместо телефона. Строку нужно удалить перед
реальным запуском — рядом оставлен комментарий.

## Что нужно заменить перед публикацией

Сайт сознательно не содержит выдуманных данных. Всё, что неизвестно, оставлено явными
заглушками — их видно и в интерфейсе, и в коде.

| Что | Где | Текущее значение |
| --- | --- | --- |
| Телефон, WhatsApp, VK | `src/data/company.ts` → `contactChannels` | `PHONE_PLACEHOLDER`, `WHATSAPP_PLACEHOLDER`, `VK_PLACEHOLDER` |
| Адрес и режим работы | `src/data/company.ts` → `contactDetails` | `ADDRESS_PLACEHOLDER`, `HOURS_PLACEHOLDER` |
| Ссылка на карточку компании | `src/components/Reviews.tsx` | `REVIEWS_LINK_PLACEHOLDER` |
| Фотографии работ | `src/assets/images/work-*.svg` | абстрактные заглушки с меткой `DEMO` |
| Фото для услуг и hero | `src/assets/images/service-*.svg`, `hero.svg` | то же |
| Домен в canonical и Open Graph | `index.html` | `https://example.com/` |
| Обложка для соцсетей | `public/og-cover.svg` | заглушка; заменить на JPG/PNG 1200×630 |
| Favicon | `public/favicon.svg` | временный знак «R» |
| Дисклеймер о демо-изображениях | `src/components/Works.tsx`, `src/components/Contacts.tsx` | удалить после замены фотографий |

### Как заменить изображения

1. Положить реальные фотографии в `src/assets/images/` (JPG или WebP).
2. В `src/data/works.ts` обновить `src`, `width`, `height` и `alt` для каждой работы.
   `width`/`height` — реальные пиксельные размеры: они резервируют место и убирают layout shift.
3. `cols` и `ratio` задают раскладку плитки в шестиколоночной сетке на десктопе. Значения `ratio`
   подобраны так, чтобы каждый ряд закрывался вровень; при изменении `cols` пересчитайте `ratio`
   (высота ряда = ширина в колонках ÷ ratio — у соседей по ряду она должна совпадать).
4. Аналогично для услуг — `image` и `imageAlt` в `src/data/services.ts`.

### Данные, подтверждённые карточкой компании

Рейтинг 4.6, 37 оценок, три услуги с ценами (25 000 ₽ / 16 000 ₽ / 65 000 ₽) — в
`src/data/company.ts` и `src/data/services.ts`. Никаких других фактов о студии на сайте нет:
ни гарантий, ни сроков, ни имён, ни отзывов клиентов.

## Структура

```
src/
  components/   компонент + его CSS рядом
  data/         контент и настройки (услуги, галерея, контакты, тексты блока «Почему Reality»)
  hooks/        useReveal, useScrollLock, useFocusTrap
  styles/       tokens.css (палитра, шрифты, шкала) и base.css (сброс, примитивы)
  assets/       изображения
public/fonts/   Manrope и Inter (woff2, latin + cyrillic) — подключены локально,
                чтобы сайт не зависел от внешних CDN
```

## Технические решения

- **Тёмная монохромная палитра** с единственным акцентом (`--accent`, тёплая медь) —
  он используется только в мелких элементах: индексы секций, подчёркивания при наведении,
  фокус, шкала рейтинга.
- **Две гарнитуры**: Manrope (заголовки) и Inter (текст). Обе с кириллицей, подключены локально.
- **Галерея** — CSS Grid с фиксированными пропорциями плиток: 1 колонка на телефоне,
  2 на планшете, 6-колоночная композиция на десктопе. Лайтбокс закрывается по Escape и клику
  вне изображения, листается стрелками, клавиатурой и свайпом, удерживает фокус внутри
  и возвращает его на исходную плитку.
- **Доступность**: семантические landmark-элементы, один `h1`, `alt` у всех изображений,
  видимый фокус, области нажатия не меньше 44–48 px, `prefers-reduced-motion` отключает
  все переходы и появления.
- **Анимации** ограничены появлением при скролле, hover-состояниями и переходом лайтбокса.
